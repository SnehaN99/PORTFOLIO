PROJECT 01 / FEATURED

DecoyShield

A Honeypot-Based System for Threat Detection

WHAT WAS IT?

A honeypot-based system using fake or decoy ports to attract suspicious connections, capture attacker-related information and analyze behavior in a controlled environment.

WHY I BUILT IT

To understand how an attack occurs, how attackers interact with a system and how collected activity can be analyzed to determine whether behavior is malicious.

OBJECTIVE

Build a controlled deception environment that can attract suspicious activity, record relevant events and support threat-level analysis.

TECHNOLOGIES
PythonPyQtSQLiteKali Linux
WHAT I DID
  • Created decoy ports and services.
  • Implemented real-time connection monitoring.
  • Logged attacker IP addresses and activity.
  • Stored security events using SQLite.
  • Performed threat-level analysis and monitoring.
  • Generated reports from collected activity.
SKILLS DEVELOPED
Honeypot deploymentNetwork traffic analysisBehavior analysisSecurity loggingThreat detection
OUTCOME

Developed a working honeypot system that detects and records suspicious network connections through decoy ports.

REAL-WORLD RELEVANCE

The project demonstrates the workflow of collecting network security events from a controlled deception environment and turning those events into evidence for monitoring and analysis — concepts relevant to SOC and threat-detection work.
